Eight logged decisions, three chapters, zero dollars spent — the whole build lived in time, not budget. The shape of it: figure out why the site should exist and where the code lives, pick a stack and a look that actually fit four unrelated interests, then make the case for showing up in public before flipping the switch.

The throughline across all three chapters is the same one the site itself is about: taking a thing apart to see what it's really made of. That happened literally with the color palette (oklch() percentages that looked generated, rebuilt in plain hex) and figuratively with the speaking page (a booking form that turned out to need a credibility strategy first).
